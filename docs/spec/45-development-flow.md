# 45. 开发执行流程

每个 Phase 都按以下流程执行：

1. 检查当前项目状态。
2. 明确本阶段目标。
3. 编写或更新设计文档。
4. 实现功能。
5. 运行格式检查、静态检查。
6. 运行单元测试、集成测试。
7. 执行构建。
8. 修复发现的问题。
9. 更新文档与 STATUS.md。
10. 记录未解决问题。
11. 汇报阶段结果（已完成、修改的文件、已执行的测试、测试结果、当前限制、未完成任务、下一阶段计划）。

不得一次性生成大量未经验证的代码，然后宣称整个 Phase 已完成。遇到阻塞时：说明问题与影响范围，提供可行方案；需要用户决策时暂停，同时继续推进不受影响的工作。
