# 19. Sound Manager

用户必须可以自定义提示音。

- 分类：全局提示音、稀有度提示音、每日等级提示音、成就专属提示音、普通 Commit 提示音。
- 格式：WAV、MP3、OGG。
- 管理：导入、删除、重命名、预览、音量调整、静音、恢复默认、配置导入导出。
- 优先级：成就专属 > 每日等级 > 稀有度 > 全局；普通 Commit 使用独立策略。
- 资源缺失或加载失败时安全回退到默认音效。
- 分阶段：Phase 2a 只要求内置默认音效与基础播放，Phase 2b 增加音量与静音，完整 Sound Manager 在 Phase 4a。

# 20. Asset Manager

- 资源类别：全局图片、稀有度图片、成就图标、每日等级图标。
- 格式：PNG、JPG、WebP；SVG 必须经过安全处理；GIF 放在后续版本。
- 功能：预览、裁剪、缩放、替换、恢复默认、缺失资源回退。
- 不得执行用户导入图片中的任何脚本或代码；限制文件大小并校验真实文件类型。
- 分阶段：Phase 2 使用内置默认资源，完整 Asset Manager 在 Phase 4a。

# 21. Popup Editor

| 属性 | 范围 |
| --- | --- |
| 宽度 | 280–600 px |
| 高度 | 自动或自定义 |
| 缩放 | 70%–150% |
| 图片尺寸 | 32–160 px |
| 圆角 | 0–32 px |
| 屏幕边距 | 0–100 px |
| 位置 | 四角、多屏幕 |
| 其他 | 透明度、背景模糊、显示时长、动画速度 |

必须提供实时预览；桌面与浏览器弹窗可分别配置，但遵循统一视觉规范。分阶段：Phase 2 使用默认外观，完整 Popup Editor 在 Phase 4a。
