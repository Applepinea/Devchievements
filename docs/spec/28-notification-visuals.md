# 28. 通知视觉规范

## 28.1 默认样式

深色横向矩形弹窗：左侧图标，右侧文字，顶部 `ACHIEVEMENT UNLOCKED`，底部显示稀有度。默认尺寸 `360 × 110 px`，默认位置右下角，距边缘 24 px。不使用 Steam 官方 Logo、图标或未经授权的品牌资产。

## 28.2 稀有度与显示时长

稀有度越高，视觉表现越明显（边框、背景效果、图标、动画、提示音）；Legendary 使用更明显的动画和专属音效。

| 稀有度 | 默认时长 |
| --- | --: |
| Common | 5 秒 |
| Uncommon | 5 秒 |
| Rare | 6 秒 |
| Epic | 7 秒 |
| Legendary | 8 秒 |

## 28.3 动画

默认：从右侧滑入、短暂停留、淡出；支持用户调整动画和时长；必须尊重系统的减少动态效果设置。
