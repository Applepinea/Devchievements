# 22. Achievement Builder

首发提供 JSON 高级模式，可视化编辑器放在后续版本。

- 可自定义：名称、描述、图标、事件类型、事件数量、时间范围、仓库、连续活跃天数、AND / OR 逻辑、稀有度、专属音效、专属图片、是否隐藏、是否允许重复解锁。
- JSON 规则必须有 Schema、类型校验、数量范围限制、防无限递归、版本控制和清晰的错误提示；不允许执行任意代码。
- 内置成就与用户成就共用 Engine，但必须区分规则来源、统计口径、规则版本和历史回填策略；用户规则不得改变内置成就的判定结果。

**复杂度与确定性限制**

- 最大嵌套深度默认 5，最大条件数默认 50（可配置，但有硬上限）。
- 规则之间不允许相互引用，因此不存在循环引用。
- 评估使用确定性的步数预算：单次评估超出预算时，该规则被视为无效并禁用，写入诊断日志并通知用户。不得使用墙钟超时，因为它会破坏确定性与 Golden Tests。
- 校验在保存规则时执行；Phase 1 实现这些限制并附测试。
