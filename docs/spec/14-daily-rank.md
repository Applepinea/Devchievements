# 14. 每日等级与每日里程碑

## 14.1 默认等级

| 等级 | 每日有效 Commit 数量 |
| --- | --: |
| Common | 1 |
| Uncommon | 2–4 |
| Rare | 5–9 |
| Epic | 10–19 |
| Legendary | 20+ |

## 14.2 规则

- 默认合并统计所有仓库；未来允许单仓库等级统计。
- 默认使用用户本地时区，每日 00:00 开始，可配置。
- 每日等级与每日里程碑可以每天重复获得，必须与永久成就分开存储。
- 用户可以自定义每日等级阈值，但不影响内置永久成就的固定阈值。

## 14.3 通知

- 每天首次达到某个等级时才触发完整升级通知；同一日内重复达到同一级别不重复通知。
- First Commit 与 Common 同时触发时合并为一条通知。
