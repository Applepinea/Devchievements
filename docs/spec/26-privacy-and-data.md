# 26. 隐私与数据管理

## 26.1 Local-first

默认所有活动数据存储在本地。不得默认上传：Git 历史、Commit Message、仓库名称、PR 标题、Issue 内容、用户活动记录。不得默认开启遥测；遥测必须明确获得用户同意。

## 26.2 Privacy Mode

- 行为：隐藏仓库名称、Commit Message、PR 标题；使用通用通知文案；隐藏锁屏通知预览中的敏感信息。
- 示例：正常模式显示成就名与仓库名；Privacy Mode 只显示成就名与通用文案「A new milestone has been reached」。
- 不得宣称 Privacy Mode 等于数据加密。屏幕共享状态无法可靠自动检测，因此提供手动开关与托盘快捷入口。

Privacy Mode 同样作用于诊断页和日志展示；诊断包导出默认脱敏（仓库名替换为稳定别名，路径中的用户名与邮箱打码）；用户可以选择包含原始信息，但必须有明确警告。日志默认不包含 Commit Message 与 Token。

## 26.3 Token

Token 必须使用操作系统安全存储，不得写入普通配置文件、Git 仓库、日志或调试输出，也不得出现在错误信息中。

## 26.4 数据管理

配置版本化；配置导入导出；数据库备份与恢复（含完整性检查）；资源管理；安全删除；恢复默认设置；数据库迁移必须兼容旧版本。导入外部配置时必须校验，不得直接信任。

**存储配额**：自定义音效和自定义图片单个文件默认不超过 5 MB，自定义资源总量默认不超过 200 MB（均可配置）；占用达到 80% 时提示用户。Browser Only 使用 IndexedDB 配额估算，接近上限时提示导出备份。数据库增长纳入存储健康诊断。
