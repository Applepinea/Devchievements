# 11. 历史导入

## 11.1 导入选项

首次启动与 Repository Manager 都必须提供：仅统计安装后的活动（默认）；导入选定仓库的历史；导入用户指定目录下发现的全部仓库。不得默认扫描整个磁盘。

## 11.2 导入要求

- 前置条件：已配置 Git Email（见用户身份识别）。
- 分批读取，可显示进度、可取消、可断点续传；使用 Commit 原始时间计算 `local_date`，不得把历史 Commit 全部算入导入当天。
- 事件标记为 `imported`，使用统一的去重规则；只导入匹配用户邮箱的 Commit。
- 导入期间静默：不逐条播放音效、不逐条显示成就弹窗、不逐条生成 Outbox 通知；完成后最多生成一条汇总通知。
- 导入完成后在同一批事务中重建投影，历史回填解锁成就时记录解锁来源与使用的规则版本。
- 导入可以在之后随时对新增仓库重复执行，重复执行必须幂等。
