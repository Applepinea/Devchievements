# 15. 事件过滤器

- 可过滤的统计类型：Commit、Release、PR、Issue、Repository Creation、Star Given、Merge、连续活跃天数。
- 过滤条件：所有仓库、指定仓库、排除仓库、组织、个人仓库、作者、Merge 类型、历史数据、时间范围、来源可信度。
- 内置永久成就使用固定统计口径；用户自定义成就可以使用用户过滤器。
- Dashboard 和普通统计尊重用户过滤设置，界面上必须标明统计口径（见桌面 UI 一章）。
