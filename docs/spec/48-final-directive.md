# 48. 最终执行指令

请先完整阅读本规范，不要立即开始大规模编码。

1. 检查当前工作目录、现有文件和 Git 状态。
2. 检查开发环境与工具链。
3. 分析规范中可能存在的技术风险。
4. 建立项目目录规划，创建初始 AGENTS.md 与 STATUS.md。
5. 制定 Phase 0 实施计划。
6. 执行 Phase 0 技术验证与 Git 行为实验。
7. 汇报 Phase 0 结果。

完成 Phase 0 后，按照阶段顺序逐步推进，并严格遵守三个人工检查点。

**最终目标不是做出一个能显示成就弹窗的 Demo，而是交付一个稳定、可扩展、可维护、跨平台、具有完整本地数据闭环的开发者成就系统。**
