# 25. 安装向导与系统托盘

## 25.1 安装向导

首次启动时检测：操作系统、浏览器、Git 环境与版本、Native Messaging 环境、Hook 冲突、Git 邮箱配置。

提供：运行模式选择、Git 邮箱配置、Hook 安装、历史导入选项、Native Messaging 注册（Phase 3b 起）、测试事件、通知测试。任何会修改用户 Hook 或 Git 配置的操作，都必须说明原因并提供撤销方式。

## 25.2 系统托盘

必须支持：打开主窗口、暂停通知、启用通知、切换运行模式（Phase 3b 起）、打开设置、退出程序。托盘不可用的环境见「平台兼容性与降级」。

## 25.3 后台运行

用户关闭主窗口后，Companion 可以按设置继续后台运行；退出程序必须真正停止相关后台任务。
