# Devchievements

让每一次代码提交，都成为值得收藏的成就。

编写代码 · 提交成果 · 解锁成就

Devchievements 是一款面向开发者的本地成就系统，将日常开发活动转化为游戏化的成就、等级与里程碑。

每一次代码提交、每一个项目、每一次技术突破，都值得被记录。

让开发不再只有代码，还有值得收藏的成长记录。

⸻

✨ 核心功能

🏆 成就系统

将开发过程中的各种活动转化为可解锁的成就。

* 编程成就：记录代码提交、编程活动和开发里程碑。
* GitHub 成就：记录仓库、拉取请求、议题等活动。
* 项目成就：追踪项目创建、开发进度和重要版本。
* 学习成就：记录技术探索与知识积累。
* 隐藏成就：发现特殊条件，解锁隐藏奖励。

成就解锁后将永久保存，不会因为后续活动变化而丢失。

📈 开发者等级

让每天的开发活动都有迹可循。

* 根据每日代码提交次数计算等级进度。
* 记录每日开发里程碑。
* 查看个人开发活动和历史记录。
* 追踪长期开发进度。

🔔 成就通知

重要时刻，不应该悄无声息。

* Windows 桌面成就通知。
* 成就解锁音效。
* 等级提升提醒。
* 自定义通知外观与提示音。

🎨 个性化设置

打造属于自己的成就体验。

* 自定义成就通知图片。
* 自定义提示音。
* 调整通知窗口大小。
* 自定义部分成就规则与统计范围。

🔒 本地优先

你的开发数据应该由你掌控。

* 本地保存成就和活动记录。
* 尽可能减少不必要的数据收集。
* 明确区分本地 Git 事件与 GitHub 平台数据。
* 外部账号授权遵循最小权限原则。

🛠️ 技术架构

Devchievements 采用模块化架构，将成就判定、数据采集、持久化存储和通知系统分离。

核心设计目标：

* 模块化架构：各功能模块保持低耦合。
* 事件驱动引擎：通过统一事件模型处理开发活动。
* 本地数据存储：持久化保存成就和活动数据。
* 可扩展集成架构：为未来接入其他平台预留扩展能力。
* 可靠通知机制：通过可靠的事件队列处理通知任务。
