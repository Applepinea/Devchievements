# Devchievements

让每一次代码提交，都成为值得记录的成就。

Devchievements 是一个面向开发者的本地成就系统，通过 Git 和 GitHub 活动记录开发过程，并将其转化为成就、等级和每日里程碑。

项目希望为日常开发增加一些游戏化元素，让代码提交、项目进展和长期积累变得更加直观。

功能

成就系统

* 根据 Git 和 GitHub 活动解锁成就。
* 支持编程、项目、社区协作和开发里程碑等成就类别。
* 支持隐藏成就。
* 成就解锁记录永久保存。

每日等级

* 根据每日 Commit 次数计算等级进度。
* 记录每日开发活动。
* 查看历史活动和等级变化。
* 支持每日里程碑。

桌面通知

* Windows 桌面成就通知。
* 成就解锁和等级提升提醒。
* 通知提示音。
* 支持自定义通知图片、音效和窗口大小。

自定义设置

* 自定义部分成就规则和统计范围。
* 调整通知外观和提示音。
* 管理成就及活动记录。

本地数据管理

* 成就和活动记录保存在本地。
* 区分本地 Git 事件与 GitHub 平台事件。
* 外部账号授权遵循最小权限原则。

技术架构

项目采用模块化、事件驱动的设计，将数据采集、成就判定、本地存储和通知处理分离。

主要设计方向：

* 使用统一事件模型处理不同来源的开发活动。
* 将成就判定逻辑与具体平台的数据接口分离。
* 使用本地数据库保存成就和活动记录。
* 通过事件队列处理通知任务。
* 为未来增加其他平台集成预留接口。
